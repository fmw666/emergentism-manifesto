# 第一章：虚无主义判别器

<ArticleMetadata />

## 3.1 核心命题

本章定义 EvoMap 在“意义层”上的适应度目标：不是让回答更复杂，而是让连接更可持续，让生命感更稳定。

## 3.2 判别器的职责

虚无主义判别器用于评估一次交互是否会把用户推向以下状态：

- 情绪耗散（短期平静、长期空洞）
- 关系断裂（问题被解答，但信任没有累积）
- 价值坍缩（效率上升，但意义下降）
